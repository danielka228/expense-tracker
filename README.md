# СпендТрекер — трекер расходов

Простое веб-приложение на Flask: регистрация, вход, добавление трат по дням, статистика за день/неделю/месяц и по категориям.

## Что внутри
- `app.py` — вся логика (Flask + SQLAlchemy)
- `templates/` — страницы (вход, регистрация, дашборд)
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для хостинга

## Как задеплоить бесплатно на Render.com

1. **Зарегистрируйся на Render**
   Зайди на https://render.com и войди через GitHub (если аккаунта на GitHub нет — сначала зарегистрируйся на https://github.com, это тоже бесплатно).

2. **Залей код на GitHub**
   - Создай новый репозиторий на GitHub (например `expense-tracker`).
   - Загрузи туда все файлы из этой папки (можно просто перетащить файлы через веб-интерфейс GitHub — кнопка "Add file" → "Upload files").

3. **Создай Web Service на Render**
   - На Render нажми "New" → "Web Service".
   - Выбери свой репозиторий `expense-tracker`.
   - В настройках укажи:
     - **Runtime**: Python 3
     - **Build Command**: `pip install -r requirements.txt`
     - **Start Command**: `gunicorn app:app`
   - Внизу в разделе "Environment Variables" добавь одну переменную:
     - `SECRET_KEY` = любая случайная строка (например `mySecretKey12345`)

4. **Добавь бесплатную базу данных (PostgreSQL)**
   Данные на бесплатном тарифе Render без базы могут стираться при перезапуске, поэтому:
   - На Render нажми "New" → "PostgreSQL", выбери Free план, создай.
   - Скопируй "Internal Database URL" из настроек базы.
   - Вернись в свой Web Service → "Environment" → добавь переменную `DATABASE_URL` со значением этого URL.

5. **Нажми Deploy**
   Через пару минут Render даст тебе ссылку вида `https://expense-tracker-xxxx.onrender.com` — это и есть твоё приложение.

### Важно про бесплатный тариф
Бесплатные сервисы на Render "засыпают" после 15 минут без активности и просыпаются секунд 30-50 при следующем заходе — это нормально, просто особенность бесплатного тарифа.

## Запуск на своём компьютере (для проверки)
```bash
pip install -r requirements.txt
python app.py
```
Открой в браузере: http://localhost:5000
