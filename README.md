# СпендТрекер — трекер расходов

Веб-приложение: регистрация, вход, траты по дням с заметками, статистика за день/неделю/месяц
и по категориям, рейтинг друзей, фото профиля, быстрые траты с iPhone через «Команды».

Работает на **Cloudflare Workers**, база данных — **Cloudflare D1** (SQLite). Сайт не «засыпает», как на бесплатном Render.

Сайт: https://expense-tracker.hhoh7327.workers.dev

**Обновление сайта:** после мержа в `main` GitHub сам выкладывает новую версию на Cloudflare
(Actions → «Переезд на Cloudflare»). Нужны секреты `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.

**Сканер покупок:** кнопка «Сканировать» открывает камеру. Наведи на штрих-код — сайт найдёт товар
в открытой базе Open Food Facts, по геопозиции предложит магазин рядом (данные OpenStreetMap) и подставит цену
из прошлых покупок этого товара. Геопозиция запрашивается только в момент сканирования.

**Демо-версия:** `expense-tracker-preview` — отдельный сайт со своей базой и кнопкой «Войти в демо-аккаунт».
Выкладывается вручную: Actions → «Переезд на Cloudflare» → Run workflow → target: `preview`. Основной сайт не трогается.

**Голосовой ввод:** кнопка «Голосом» на главной. Скажи, например, «кофе с другом 350»,
«вчера такси 1 200» или «2 тысячи на продукты» — сумма, категория, заметка и дата заполнятся сами.
Пока говоришь, эквалайзер показывает звук с микрофона. Работает в Safari и Chrome.

**Telegram-бот:** пишешь или надиктовываешь голосовым «кофе 250» или «вчера такси 540», и трата появляется на сайте.
Голосовые распознаёт Whisper на Cloudflare Workers AI (до минуты; в бесплатном лимите Cloudflare).
Бот угадывает категорию; под каждой записью есть кнопки «Категория» и «Удалить». Команды:
/stats — сводка, /last — последние траты, /undo — удалить последнюю, /unlink — отключить.
Подключение: на сайте «Профиль» → «Подключить Telegram».

Как включить бота (один раз):
1. В Telegram открой @BotFather → `/newbot`, придумай имя и ник бота (ник должен заканчиваться на `bot`).
   BotFather пришлёт токен вида `123456789:AAE…`.
2. В GitHub: Settings → Secrets and variables → Actions → New repository secret,
   имя `TELEGRAM_BOT_TOKEN`, значение — токен. Токен никому не отправляй.
3. Запусти выкладку: Actions → «Переезд на Cloudflare» → Run workflow (или просто влей PR).
   Workflow сам передаст токен в Cloudflare и подключит бота к сайту.

## Что внутри
- `src/index.ts` — вся логика (маршруты, работа с базой)
- `src/views.ts`, `src/styles.ts` — страницы, виджеты и тёмная тема
- `src/client.ts` — скрипты для браузера: голосовой ввод, эквалайзер, анимации
- `src/lookup.ts` — поиск товара по штрих-коду и магазинов рядом, история цен
- `src/parse.ts` — разбор фраз «кофе 250» (общий для голосового ввода и Telegram-бота)
- `src/telegram.ts` — Telegram-бот
- `public/` — иконка приложения; `public/vendor/` собирается из npm при деплое (распознаватель штрих-кодов для iPhone)
- `src/passwords.ts` — проверка паролей; старые пароли из Flask-версии подходят
- `migrations/0001_init.sql` — схема базы D1
- `migrate/export_to_d1.py` — перенос всех данных со старой базы Render в D1
- `wrangler.jsonc` — настройки Cloudflare

Старая Flask-версия (`app.py`, `*.html`, `requirements.txt`, `Procfile`) пока лежит в репозитории,
чтобы Render продолжал работать до переезда. После переезда эти файлы можно удалить.

## Переезд с Render на Cloudflare (один раз)

Нужен Node.js 20+ и Python 3.

1. **Установи зависимости и войди в Cloudflare**
   ```bash
   npm install
   npx wrangler login
   ```

2. **Создай базу D1**
   ```bash
   npx wrangler d1 create expense-tracker
   ```
   Скопируй `database_id` из вывода в `wrangler.jsonc` (вместо нулей) и создай таблицы:
   ```bash
   npm run db:migrate
   ```

3. **Задай секретный ключ** (любая длинная случайная строка, можно не ту, что была на Render):
   ```bash
   npx wrangler secret put SECRET_KEY
   ```

4. **Задеплой сайт**
   ```bash
   npm run deploy
   ```
   Wrangler покажет адрес вида `https://expense-tracker.<твой-аккаунт>.workers.dev`.

5. **Перенеси данные.** Делай это прямо перед переключением, чтобы не потерять свежие траты.
   - На Render открой Web Service → **Settings → Suspend**, чтобы никто не добавлял траты во время переноса.
   - На Render открой базу PostgreSQL → **Connect → External Database URL**, скопируй.
   - Выгрузи и загрузи данные:
     ```bash
     pip install sqlalchemy psycopg2-binary
     python migrate/export_to_d1.py "ВСТАВЬ_EXTERNAL_DATABASE_URL" migrate/dump.sql
     npx wrangler d1 execute expense-tracker --remote --file=migrate/dump.sql
     ```
   Скрипт покажет, сколько перенесено пользователей, трат, друзей, фото и токенов.
   Загружать дамп нужно в пустую базу: при повторной загрузке будут ошибки из-за совпадающих ID.

6. **Проверь** новый адрес: зайди под своим логином и паролем, всё должно быть на месте.
   После этого сервис и базу на Render можно удалить.

### Что поменяется для пользователей
- Логины, пароли, траты, заметки, друзья, фото и токены сохраняются.
- Всем один раз придётся заново войти (сессии со старого сайта не переносятся).
- **iPhone-команда «Трата»** отправляет запросы на старый адрес `...onrender.com/api/add`.
  Открой команду в «Командах», замени адрес на `https://<новый-адрес>/api/add`,
  поделись ей заново и задай новую ссылку на iCloud:
  ```bash
  npx wrangler secret put SHORTCUT_URL
  ```
  Тем, кто уже поставил команду, нужно поменять адрес у себя. Токены остаются прежними.
  Если подключить к Worker свой домен (Cloudflare → Workers → Settings → Domains & Routes),
  адрес больше никогда не придётся менять.

### Тариф Cloudflare
На бесплатном тарифе Workers запросу даётся 10 мс процессорного времени. Пароли старых
пользователей зашифрованы алгоритмом scrypt, и его проверка занимает около 100 мс, поэтому
первый вход старого пользователя на бесплатном тарифе может упасть с ошибкой. После первого
успешного входа пароль автоматически пересохраняется в более лёгком формате.
Надёжный вариант — тариф Workers Paid ($5/мес, лимит 30 секунд).

## Запуск на своём компьютере
```bash
npm install
echo "SECRET_KEY=dev" > .dev.vars
npm run db:migrate:local
npm run dev
```
Открой в браузере: http://localhost:8787
